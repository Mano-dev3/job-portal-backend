# Job Portal Backend

A backend REST API for a Job Portal application built using Spring Boot, Spring Security, JWT Authentication, MySQL, and Maven.

## 🚀 Features

- User Registration
- User Login with JWT Authentication
- Post Jobs
- View Jobs
- Apply for Jobs
- Role-Based Authentication
- RESTful APIs
- MySQL Database Integration

## 🛠️ Technologies Used

- Java 17
- Spring Boot
- Spring Security
- JWT
- Maven
- MySQL
- JPA / Hibernate

## 📁 Project Structure

```
src/
 ├── controller/
 ├── service/
 ├── repository/
 ├── entity/
 ├── dto/
 ├── security/
 └── resources/
```

## ▶️ Run the Project

1. Clone the repository

```
git clone https://github.com/Mano-dev3/job-portal-backend.git
```

2. Open the project in Eclipse or IntelliJ IDEA.

3. Configure MySQL in `application.properties`.

4. Run:

```
mvn spring-boot:run
```
